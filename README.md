# gaokao-agent-tutor · 高考陪学闭环（Agent 代搭）

> 学生只管聊天，搭建是 agent 的活。

把这套仓库交给任意 coding agent（TRAE / Claude Code / Codex / Cursor），说一句话，它会把整套陪学系统装进你的文件夹。学生不需要会 git、不需要碰文件结构、不需要跑脚本——**学生的全部界面就是一个对话窗口**。

## 它解决什么

刷题 App 管题不管「你」，笔记软件记完没人回顾。这套闭环的核心是四个机制：

| 机制 | 是什么 | 对抗什么 |
|------|--------|----------|
| 恢复入口 | 每科一页：今天到哪、明天第一步、薄弱点 ≤3 条 | 断档——隔三天再学，不知道从哪接 |
| 复习队列（退火） | 卡→次日，一般→+3 天，掌握→+7 天（封顶 14） | 遗忘曲线 |
| 两级验收 | 真过 = 独立做出变式；放行 = 点头算过 | 「看懂了」的错觉 |
| 开场递送 | agent 每天开场只递一条最该做的事 | 建了系统没人翻（递送而非陈列） |

## 安装（一句话）

clone 或下载本仓库后，在任意 coding agent 的对话里说：

> 读 `skills/setup/SKILL.md`，按它给我搭一套高考陪学。

agent 会问你 4 个问题（科目 / 教材 / 高考日期 / 每天时长），其余全自动：建 vault、装协议、配递送脚本、跑自检，最后告诉你每天怎么用。

## 日常长什么样

```
学生：继续
教练：↑数学复习到期：隐零点设而不求（超期 1 天）——先销这个，还是继续昨天的新题？
学生：先销复习
教练：（出 1 道小复现题 → 学生做 → 按表现更新队列日期）
……
教练：收尾快照：今天真过 2 个点，放行 1 个，薄弱点剩 1；明天第一步：题04 零点比较；
      距高考 273 天。
```

学生全程只说人话；文件、队列、日志、commit 都由教练侧完成。

## 目录

```
gaokao-agent-tutor/
├── skills/setup/SKILL.md     # 安装器：agent 读它执行搭建（不装进学生 vault）
├── install/                   # 会被装进学生 vault 的全部内容
│   ├── AGENTS.md              # 教练协议模板（{{占位符}} 由安装器渲染）
│   ├── templates/             # 恢复入口 / 题目笔记模板
│   ├── tools/                 # delivery_gen.py（递送聚合）/ delivery_stats.py（接受率统计）
│   └── skills/weekly-review/  # 周复盘 skill
└── examples/gaokao-math-derivative/   # 一次真实安装的产物（高考数学·导数专题）
```

## 三条原则

本系统的机制都从这三条推出来，改机制前先问是否违背它们：

1. **递送而非陈列** —— 记忆、进度、薄弱点由 agent 在对话里递到学生面前，不建「等学生自己打开」的页面。
2. **记录不评判** —— 日志只记事实和感受；模式分析交给每周复盘，不当场批评。
3. **验收主动权在学生** —— 教练不代判「过」；点头算放行，独立做出变式才算真过。

## 依赖

- 一个能读写本地文件的 AI agent（TRAE / Claude Code / Codex / Cursor 等任一）
- Python 3.8+（跑递送脚本；没有也能用，协议里有降级方案）
- Obsidian 可选（纯文件夹照常工作，Obsidian 只是更好的阅读器）
- git 可选（自动回滚点）
