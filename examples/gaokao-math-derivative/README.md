# 示例：一次真实安装的产物

这是 `tutor-setup` 对一位高三学生的安装结果：**数学 · 导数专题**（人教A版选择性必修第二册 + 五三），高考 2027-06-07，每天 60 分钟。

```
gaokao-math-derivative/        ← 学生 vault 根
├── AGENTS.md                  # 渲染后的教练协议（占位符已填）
├── tutor.json                 # exam_date / daily_minutes / subjects
├── 数学/
│   ├── 00-恢复入口.md          # 今天到哪 / 今天优先 / 薄弱点 / 复习队列
│   ├── 题01-切线方程与过点切线.md
│   ├── 题02-极值点偏移.md
│   └── 题03-隐零点.md
└── daily/
    └── 2026-09-07.md          # 今日递送（脚本生成）+ Agent 记录（教练流水）
```

看什么：

1. `数学/00-恢复入口.md` —— 断档后重开对话，读这一页就能接上。
2. `daily/2026-09-07.md` 的「今日递送」小节 —— `python tools/delivery_gen.py` 的真实输出（两条到期复习 + 一条薄弱点）。
3. `数学/题02-极值点偏移.md` —— 题目笔记的样子：我的思路照实记卡点，变式做完才改 `variant-done`。

> 注：本示例省略了 `tools/`、`skills/`、`templates/`（安装时从 `install/` 原样拷入）。
