# 周复盘（高考陪学版）

## 输入

1. 本周 7 天的 `daily/*.md`（每天做了什么、递送埋点）
2. 各科 `00-恢复入口.md` 的本周变化（git 可用时看 `git log --stat`，不可用就让学生口述印象）
3. `python tools/delivery_stats.py --weeks 1`（递送接受率）

## 输出

写 `daily/weeks/YYYY-WXX.md`（周一记周），四段：

```markdown
# YYYY-WXX 周报

## 本周数字
- 学习 N 天 / 真过 X 个 / 放行 Y 个 / 薄弱点 +A -B
- 递送 M 条，接受率 P%

## 做成了什么
（3-5 条事实，先说做成——复习队列销了几条、哪个专题闭环了）

## 观察（计划 vs 实际）
（只描述模式，不下判断。例：计划每天 60 分钟，实际集中在周末——
 平时改 20 分钟轻量模式会不会更稳？）

## 下周一个建议
（只给一个，可以拒绝；倒计时更新：距高考 N 天）
```

## 风格红线

- **不批评人**。差距描述为「观察」，选项递给学生，主动权在他。
- 周报 ≤40 行——超过说明在写论文，不是复盘。
- 不比较「别人家的进度」，只对照学生自己的计划和上周。
